# StormAFK

Application Windows portable.

## Télécharger

[Télécharger StormAFK.exe](https://github.com/Wesleeeey/StormAFK/releases/latest/download/StormAFK.exe)

Les réglages et l’historique existants restent conservés sur ton PC.

## Mises à jour

À partir de la version 1.6.10, StormAFK vérifie les nouvelles versions au démarrage, puis toutes les 30 minutes. Un bouton **Mettre à jour** apparaît dans l’application. Tu peux aussi utiliser **Vérifier** dans les réglages.

Le téléchargement est vérifié avant remplacement, puis l’application redémarre. Aucun compte GitHub n’est nécessaire pour télécharger les mises à jour.

**Versions 1.6.8 et 1.6.9 :** si la mise à jour reste sur « Installation », ferme l’app et remplace une fois ton ancien fichier par le téléchargement ci-dessus. La version 1.6.10 corrige le lanceur Windows et permet les mises à jour suivantes depuis l’application.

Ce dépôt contient les téléchargements et leur documentation. Les fichiers sources ne sont pas fournis séparément. Aucun réglage personnel ni identifiant n’y est publié.
