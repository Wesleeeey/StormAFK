# StormAFK

Application Windows portable.

## Télécharger

[Télécharger StormAFK.exe](https://github.com/Wesleeeey/StormAFK/releases/latest/download/StormAFK.exe)

Les réglages et l’historique existants sont conservés sur ton PC.

## Mises à jour

À partir de la version 1.6.8, StormAFK vérifie les nouvelles versions au démarrage, puis toutes les 30 minutes. Un bouton **Mettre à jour** apparaît dans l’application. Tu peux aussi utiliser **Vérifier** dans les réglages.

Le téléchargement est vérifié avant remplacement, puis l’application redémarre. Aucun compte GitHub n’est nécessaire pour télécharger les mises à jour.

Les versions antérieures à 1.6.8 doivent télécharger cette version une première fois.

Ce dépôt contient uniquement les téléchargements et leur documentation. Aucun réglage personnel ni identifiant n’y est publié.
